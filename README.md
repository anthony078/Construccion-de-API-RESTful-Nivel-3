Esta API permitirá realizar operaciones CRUD (Crear,
Leer, Actualizar, Eliminar) sobre recursos como "Productos" y "Clientes". El objetivo
principal es alcanzar el Nivel 3 del Modelo de Madurez de Richardson, lo que implica ir
más allá de la simple utilización de HTTP como transporte y abrazar sus principios de
hipermedia

 📚 Características

- CRUD completo para recursos **Productos** y **Clientes**.
- Implementación de hipermedia con **Spring HATEOAS**.
- Arquitectura basada en capas (Controlador, Servicio, Repositorio).
- Integración con base de datos mediante **JPA/Hibernate**.
- Documentación auto-generada con **Swagger/OpenAPI**.


 ⚙️ Arquitectura y Herramientas

| Componente         | Descripción                     |
|--------------------|---------------------------------|
| Lenguaje           | Java                            |
| Framework          | Spring Boot                     |
| Base de Datos      | MySQL (via XAMPP)               |
| ORM                | JPA + Hibernate                 |
| Estándar REST      | Nivel 3 (con HATEOAS)           |
| Documentación API  | Swagger (Springdoc/OpenAPI)     |
